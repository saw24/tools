Étape 1 : Sélectionner le Formulaire (DataSet)

Veuillez d'abord vous connecter à DHIS2, puis sélectionner le formulaire dans lequel vous souhaitez importer des données.

Détails du template

Téléchargez le modèle Excel pour ce formulaire. Ce modèle contiendra toutes les colonnes nécessaires (Unités d'organisation, Période, Éléments de données).

Étape 2 : Importer le fichier Excel rempli

Glissez-déposez votre fichier Excel ici

ou cliquez pour parcourir

Utilisez le modèle téléchargé à l'étape précédente.

Étape 3 : Mapping des Colonnes

Associez les colonnes de votre fichier Excel aux champs du formulaire DHIS2. Le système a tenté une correspondance automatique.
